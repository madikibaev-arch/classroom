# Классный монитор — учебный прототип (базовая часть аналога Veyon)

Прозрачный мониторинг экранов учеников в локальной сети: преподаватель видит
экраны всех учеников сеткой и может отправить им сообщение. Агент на машине
ученика **виден** и даёт кнопку прекратить показ — это осознанный мониторинг,
а не скрытая слежка. Ставьте только на свои или школьные машины и только
с ведома пользователей.

## Что входит
- `teacher_console.py` — консоль преподавателя: сетка живых превью,
  увеличенный просмотр одного ученика по клику, рассылка сообщения всем.
- `student_agent.py` — агент ученика: видимое окно согласия, передача
  скриншотов, показ сообщений от преподавателя.

## Чего здесь НЕТ (специально)
Удалённого управления мышью/клавиатурой ученика, принудительной блокировки
машины, выключения по сети, «тихого» фонового режима. Это чувствительные
функции — для реального класса берите сам **Veyon** (бесплатный, открытый,
проверенный): https://veyon.io

## Установка
Нужен Python 3.9+.

На компьютере преподавателя:
```
pip install pillow
```
На компьютерах учеников:
```
pip install mss pillow
```

## Запуск
1. Преподаватель:
   ```
   python teacher_console.py
   ```
   Внизу окна будет показан IP и порт (по умолчанию 5005).

2. Каждый ученик:
   ```
   python student_agent.py <IP-преподавателя> <Имя>
   ```
   или просто `python student_agent.py` — программа спросит IP.

Все машины должны быть в одной локальной сети. Если превью не появляются —
скорее всего, порт 5005 блокирует брандмауэр: разрешите его на компьютере
преподавателя.

## Как это устроено
Агенты учеников сами подключаются к преподавателю (TCP, порт 5005) и шлют
JPEG-кадры экрана ~1.5 раза в секунду. Консоль собирает последний кадр от
каждого и рисует сетку. Сообщение от преподавателя уходит всем агентам и
всплывает окном. Параметры (частота кадров, качество, ширина) — вверху
`student_agent.py`.
