# Как получить установочные .exe (без ручной возни с Python у пользователей)

Внутри собранного .exe уже лежит Python — учителю и ученикам, которые
**запускают** программу, ставить ничего не нужно. Нужно один раз **собрать**
эти .exe. Есть два пути.

Проверено: конфигурация сборки корректна — сервер собирается в один файл,
вшитый шаблон консоли и связь работают.

---

## Путь A. Облачная сборка (ничего не ставить на свой компьютер)

Собирает бесплатная Windows-машина GitHub, ты просто скачиваешь готовые .exe.

1. Создай бесплатный аккаунт на https://github.com
2. Нажми «New repository», назови, например, `classroom`, создай.
3. Загрузи в него все файлы этого проекта (кнопка «Add file» → «Upload files»,
   перетащи папку целиком; важно сохранить структуру — папки `templates` и
   `.github/workflows` должны остаться на месте).
4. После загрузки открой вкладку **Actions** — сборка запустится сама
   (или нажми «Run workflow»). Через 2–3 минуты, когда появится зелёная
   галочка, зайди в этот запуск и внизу, в разделе **Artifacts**, скачай
   архив `classroom-windows-exe` — внутри `TeacherServer.exe` и
   `StudentAgent.exe`.

Всё, что для этого нужно, уже лежит в проекте: `.github/workflows/build.yml`.

---

## Путь B. Сборка на любом Windows-ПК (двойной клик)

Нужен один компьютер с Windows и установленным Python (ставится один раз).

1. Установи Python с https://www.python.org/downloads/ —
   **при установке обязательно отметь галочку «Add Python to PATH»**.
2. Положи все файлы проекта в одну папку (со структурой папок!).
3. Дважды кликни **`build_windows.bat`**. Он сам поставит нужное и соберёт.
4. Готовые файлы появятся в папке **`dist`**:
   - `TeacherServer.exe` — запускает учитель;
   - `StudentAgent.exe` — на каждом компьютере ученика.

---

## Что делать с готовыми .exe

- **Учитель:** один раз запускает `TeacherServer.exe` на своём компьютере
  (или на любом ПК в классе). Откроется чёрное окно с адресом и класс-кодом,
  и сам откроется браузер с консолью. Это окно не закрывать, пока идёт урок.
- **Ученики:** на каждом компьютере запускают `StudentAgent.exe`. Он спросит
  адрес сервера (например `192.168.1.10:8080`), класс-код и имя — и покажет
  видимое окно «ваш экран виден преподавателю».
- **Телефон учителя:** открыть в браузере телефона `http://<IP-сервера>:8080`,
  ввести класс-код. Отдельное приложение для этого не нужно.

Автозапуск ученического агента при входе в Windows (чтобы совсем «поставил и
работает») можно добавить ярлыком в папку «Автозагрузка» — скажи, распишу.

## Важно про «работает без вмешательств»
Агент ученика намеренно остаётся **видимым** (окно и баннер при управлении,
кнопка «Запретить управление»). Это удобно ставить и не трогать, но монитор
остаётся открытым и честным — не скрытым. Так и должно быть: ставить только
на свои/школьные машины и с ведома учеников.
